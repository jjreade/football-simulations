# football-simulations
In this repo we present materials relating to the research project by Stefan Szymanski, Thomas Peeters, Carl Singleton and James Reade on counter-factual exercises in football.

The primary motivation for this project is the verdict in the Burnley v Everton case - see [here](https://resources.premierleague.pulselive.com/premierleague/document/2026/06/10/14b0acd1-3d6a-41e0-a862-fffce1d6c2cc/BURNLEY-v-EVERTON-Compensation-Decision-with-Attachments-Redacted-.pdf). We argue that the judgement was flawed along a number of dimensions.

We present an alternative approach to estimating the impact of Everton's decision on the probability of harm for Burnley (i.e. relegation) to that employed in the case.
